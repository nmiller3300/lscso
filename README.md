# LSCSO

Public website and production personnel-operations portal for the Los Santos County Sheriff’s Office.

## Production architecture

- Next.js 16 App Router deployed on Vercel
- Supabase Auth for assigned department credentials
- Supabase Postgres with row-level security for personnel records
- Supabase Edge Functions for privileged account and call-sign administration
- GitHub `main` as the production source branch

No service-role key or plaintext password belongs in this repository. Supabase Auth stores password verifiers; the application never retrieves or displays a user’s password.

## Portal interface

The personnel portal uses the LSCSO Midnight dark-only interface and a shared responsive design system for Command and personnel workspaces. The secure personnel gateway uses the current LSCSO patch and the same Midnight visual system as the authenticated portal.

Preview validation branch for the finalized Personnel Portal gateway.

## Local setup

```bash
npm ci
npm run dev
```

Copy `.env.example` to `.env.local` only when overriding the project defaults. The publishable key is browser-safe; privileged keys must remain in Supabase-managed function secrets.

## Database

Migrations live in `supabase/migrations`. Apply them in timestamp order. Guardian numbers are generated by the database, beginning at G-1049. Call signs use `S-4##`; active assignments are unique and released call signs remain in history so they can be recycled safely.

Guardian acknowledgments store a typed name for negative records, an internal receipt statement, personnel/rank/call-sign snapshots, a timestamp, an optional response, and a server-generated fingerprint. IP addresses are not collected or stored.

## Account provisioning

The public bootstrap endpoint is permanently closed. Sheriff and Undersheriff credentials are assigned from the secured Personnel workspace through the authenticated `personnel-admin` Edge Function. Only the Sheriff and Undersheriff may deactivate accounts.

Temporary passwords must contain at least 12 characters with uppercase, lowercase, a number, and a symbol. Personnel can change their own password from **My account** after sign-in.
